# AI Usage Statement

AI assistance was used to help plan the project structure, draft code templates, explain debugging steps, and improve wording. The project design, dataset selection, execution, result checking, interpretation, and final submission decisions are the student's responsibility. The student should understand all code and report content before submission.

The system itself does not use an external LLM API for final predictions. It includes local retrieval-style and rule-based agent reasoning modules for reproducible coursework experiments.
